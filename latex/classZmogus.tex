\doxysubsection{Detailed Description}
Abstract base class representing a person with a first and last name. 

\doxylink{classZmogus}{Zmogus} (Lithuanian\+: "{}person"{}) serves as an abstract base class in the class hierarchy. It stores a person\textquotesingle{}s name and surname and enforces a pure virtual {\ttfamily \doxylink{classZmogus_aa52869cc6a869223fedcb9f7676534fc}{print()}} function that all derived classes must implement.

It fully satisfies the Rule of Five\+:
\begin{DoxyItemize}
\item Default and parameterised constructors
\item Copy constructor and copy assignment operator
\item Move constructor and move assignment operator
\item Virtual destructor (required for safe polymorphic deletion) 
\end{DoxyItemize}
